# 学术·现代

一句话性格：**白底藏蓝的科研正经感，现代无衬线，克制而有层次**——穿西装但不打领带。

## 形状与装饰

- 形状语言：直角或极小圆角矩形；细线分隔（1px primary 15% 透明度）；不用阴影、不用渐变、不用立体效果
- 每页至多一个大结构元素：左侧色带 / 顶部题头 / 大数字锚点，三选一
- 装饰只允许"有信息职责"的元素：序号、进度点、章节标记

## 排版层级

- 三级阶梯足够：标题 32-40 / 小节 20-24 / 正文 16-18（16:9 画幅）
- 标题左对齐，正文左对齐；居中只用于封面
- 每页一个视觉焦点：大数字卡、主图或结论句，二选一

### 字号阶梯（2026-11-04 真实课件实测校准，1280×720 画布）

> 用户在 101 页真实课件上逐页审核后的原话校准："第三页的字体大小是舒服的"。基准是目录页，不是模板初稿的保守值——旧值（正文 16-18）在投影下偏小。

| 元素 | 字号 | 备注 |
|---|---|---|
| 页面标题 | 30 粗 | 固定左上，全册同位（80,40 起，基线 y=108） |
| 列表一级 L0 | 24 | 圆点●11px 藏蓝，文字 x=104 |
| 列表二级 L1 | 22 | 圆点 9px，文字 x=148 |
| 列表三级 L2 | 20 | 圆点 8px，文字 x=192 |
| 目录条目/序号/日期 | 24 / 20 / 21 | 目录页基准（用户认可的"舒服"实例） |
| 图形页节点字 | 22-26 | 节点标签 ≥22，边标签 ≥21 |
| 代码/流程图块内 | 11.5-15 | 密集 CFG 块内可小，但整页主体不应低于 19 |
| 长列表降级（>12 条） | 19 平铺 | 宁可密集也不截断内容 |
| 行距 | 字号×1.9（舒适档） | P4/P5 实测"略大"校准；长列表溢出时降密集档（×1.35+3），宁可密不截断 |

- 正文/条目字号下限 19：低于此在投影上不可读，宁可降级列表密度

## 用色纪律

- 白底为主；primary 藏蓝承担结构（题头/序号/图表主系列）；secondary_bg 只做信息分组底色
- accent 橙是稀缺资源：**每页最多一处**——最关键的那个数字或结论
- 图表着色从 primary→secondary_accent 派生梯度，禁止引入色板外颜色

## 图形配方倾向

- 框线图：白底细边框节点 + 直角箭头；分组用 secondary_bg 底色而非加框
- 数据页：大数字锚点卡（数字 accent 或 primary，标签灰）

## 禁止清单

- 渐变、阴影、发光、艺术字、剪贴画
- 一页三种以上颜色深浅
- 全页铺满文字（>80 字/页要拆页或提炼）

## 底部安全边距（2026-11-05 实测规则，全页强制）

- **最深元素底（含文字下延）≤ 670**（720 高画布，余白 ≥50px）——意见原话："最底端不要太靠底下啊"
- 页面标题区固定 40–118；内容区 122–670；**670–720 是禁区**（页码/出页箭头除外）
- 表格页：最后一行行高压缩优先于超界；公式页：公式块整体上移，不在底部堆
- 批量生成后须跑底边距检查：扫全部 `y=` 属性 + descent(≈5px)，>670 即超
- 历史教训：37 页曾批量贴底 715–725，用户两轮意见才治理完
