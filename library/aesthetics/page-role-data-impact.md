# 数据冲击页

一页一个主数字：特大号（120-160px）accent 或 primary，单位小两档灰色；
辅数据最多 3 个小卡。数据来源脚注必带（表格编号/论文出处）。
禁止：整表粘贴（进附录）、双主数字、无来源数字。
表格确需展示时：只留 3 列以内关键列，其余省略号+脚注。
