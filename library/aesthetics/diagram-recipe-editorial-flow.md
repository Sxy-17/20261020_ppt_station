# 编辑部线框流

节点=细墨线白底方块（1.5px，直角或 2px 圆角）；连线=单字重黑线+小三角箭头；
虚线只表推断/未定关系；宋体节点标签；分组用底色不用框。

着色：全部从当前 template 的 palette 取（primary 承担主线，accent 只给当前讲解步）。
禁止：阴影、渐变、双线框、超过两种线宽。
