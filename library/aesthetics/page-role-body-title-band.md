# 正文标题带·垂直居中

## 一句话性格

正文页标题必须"长在"装饰带里——形状对齐整条带、文字垂直居中；不带装饰的素版式一律不用。

## 版式选择纪律（先盘点再选）

1. 拿到既有模板，**先解包盘点全部版式**：数每个 slideLayout 的非占位符装饰形状（decoShapes）和图片（pics）——这是判断"谁是真正文版式"的唯一可靠方法。
2. 模板常有两类版式并存：**内置素版式**（"标题和内容/仅标题"等，0 装饰）和**作者自定义版式**（"N_自定义版式"命名，带装饰 pic/shape）。**正文页一律用自定义带装饰版式**；素版式页会显得"模板丢了"，一眼假。
3. 自定义版式通常三件套：封面版式 / 正文标题带版式 / 章节过渡页版式——逐一截图确认后各归各用。

## 标题带排版纪律（本条核心）

以"1.0 项目汇报类-蓝"模板实测（画幅 33.87×19.05cm，标题带 y0–2.37cm，高 2.41cm）：

1. **标题形状 = 整条带**：标题占位符设 `y=0、height=带高(2.41cm)`，不许用版式默认的窄形状（默认 y0.41/高1.52 会让文字悬在带内上缘）。
2. **垂直居中锚点**：标题必须 `valign=middle`。占位符默认顶对齐，30pt 文字在带内肉眼可见偏上——这是最容易被用户一眼指出的毛病。
3. **字号降级**：母版标题默认 44pt，长中文标题必两行溢出（占位符高只有 ~3.5cm 可用 97pt 行高，两行 44pt 需 106pt）。**slide 级覆盖为 30pt**，一行放下；母版不动，用户仍可改。
4. **正文让路**：正文/图形起始 y ≥ 带底 + 0.4cm（本模板即 y≥2.8cm），避免任何元素压带。

## 操作配方（officecli）

```bash
# 新建正文页（用带装饰版式）后，立刻规范标题：
officecli set file.pptx '/slide[N]/shape[@id=2]' \
  --prop size="30pt" --prop y="0cm" --prop height="2.41cm" --prop valign="middle"
# 切换既有页版式（修"纯白素版式"事故）：
officecli set file.pptx '/slide[N]' --prop layout="10_自定义版式"
```

## 校验

- `officecli view <file> issues` 必须 0 overflow / 0 overlap（标题溢出与遮挡都能被它抓到）
- 截图目检一条：标题文字的视觉中心 = 装饰带的几何中心；上缘不贴边、下缘不带底
