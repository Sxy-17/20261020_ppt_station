# 学术·编辑部

一句话性格：**杂志排版感——纸白底、衬线大标题、编辑红线做标点**，像一期刊物而非一叠幻灯。

## 形状与装饰

- 编辑规则线是灵魂：题头下方一条细规则线（primary 或 accent），页边可用侧栏线
- 留白即排版：宽页边距（内容区 ≤ 70%），文字块像"文章栏目"而非卡片
- 装饰仅限：规则线、首字/首句强调、脚注式来源标注

## 排版层级

- 衬线大标题（思源宋体 36-44）+ 无衬线正文（思源黑体 16-18）——衬线只给标题和引文
- 引文块：左侧 accent 竖线 + 楷体/宋体斜排
- 页码与来源做成"刊物页脚"：小字号、细分隔线之上

## 用色纪律

- 纸白底 #FDFCF8；primary 墨黑承担全部正文结构
- accent 编辑红只做：规则线、关键术语、重要数字——像编辑用红笔点的重点
- secondary_accent 蓝灰用于图表辅助系列与脚注

## 图形配方倾向

- 框线图：手稿感——细墨线边框、宋体节点标签、虚线表示推断关系
- 时间线：中轴式，节点用小圆点+年份衬线数字

## 禁止清单

- 任何渐变、阴影、圆角卡片堆叠（那是互联网产品味）
- 大面积色块底（除封面）
- 无衬线标题配衬线正文（层级感会塌）
