# 科研进展汇报叙事流

一句话骨架：**指标先行 → 里程碑 → 技术进展 → 风险 → 下期计划**——
评审要的是"钱花得值不值、下步靠不靠谱"，不是技术细节瀑布。

## 页面骨架（12-15 页典型）

1. **封面**：项目名+汇报期（指标成果一句话放副标题——第一眼就给结论）
2. **本期指标总览**：大数字卡（完成 X/Y、达成率、对比上期）——指标是叙事锚
3. 里程碑时间轴（渐开 Morph 候选页，motion-timeline-reveal 配方）
4-8. **技术进展 3-5 页**：每页一个进展点=问题→做法→当前结果；素材锚点标明出处
9. 与指标关联分析（哪项进展支撑哪个指标——评审最关心）
10. 风险与对策（诚实的小节，反而加分）
11. 下期计划（具体到可验收）
12. 致谢/附录入口

## 纪律

- 指标页只用大数字卡，不塞表格；表格进附录
- 每个技术进展页必须能回答"这和指标什么关系"
- 素材时间线 md 的节点 = 里程碑页素材源（锚点逐条对应）
- 评审视角自检：每页删掉后故事断不断？断了才是必要页
