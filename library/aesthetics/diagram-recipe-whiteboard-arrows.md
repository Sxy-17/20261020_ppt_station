# 手绘箭头白板图

节点=短语手写体大字（无框或极淡底色块）；关系=弧线箭头（贝塞尔，单字重，
端点小三角）；不对称自由布局是特性——但**每个弧必须从词到词有语义**。

红笔规则：accent 色留给"批注层"（圈选、问号、划重点），结构层全黑白。
禁止：网格化排布（那就不是白板了）、虚线（白板上没有虚线）。
