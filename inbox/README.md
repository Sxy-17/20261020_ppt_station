# inbox/ · 用户投料区

**你（人类）往这里丢东西，agent 只读盘点、绝不动你的文件。**

## 可以丢什么

| 类型 | 去向 |
|---|---|
| .ppt / .pptx | 翻新候选（A 路线盘点后由你勾选） |
| .pdf / 论文 / 代码 / 技术报告 | B 路线素材（登记备用） |
| .md（项目管理导出的时间线等） | 叙事流素材 |
| 图片 | 素材登记 |
| 其他 | 忽略但登记在盘点清单 |

## agent 的规矩（写给接手的 AI）

1. 盘点时先过滤垃圾：`~$` 开头的 Office 锁文件、临时文件
2. 子目录递归扫描；同名异目录文件在清单里标出让你确认
3. 盘点结果只做**轻体检**（毫秒级元数据读取），重活等用户勾选
4. 本目录唯一的写操作 = **收编搬运**：仅发生在用户勾选翻新候选之后，
   文件移入 `projects/<任务>/sources/`，并写入 `projects/intake_ledger.json`
   （原始路径/大小/指纹/去向任务，可审计可回退）。取消任务时按登记簿搬回。
   除此之外一律只读，处理产物全部写进 `projects/`
5. B 路线素材不搬运（长期共享池），只在被消费时登记"被哪个任务用过"；
   盘点默认折叠已消费素材，未勾选的翻新候选继续算新货
