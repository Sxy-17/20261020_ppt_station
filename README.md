# PPT 工作台

> 将旧课件放入 `inbox/` 目录并向 AI 助手发出指令，即可批量翻新 PPT：
> 重新套用模板与排版、逐页生成新稿；用户在网页上对照审核、逐页裁决，
> 最终导出一份全部对象可编辑的 .pptx 文件。

## 功能范围

| 场景 | 操作方式 | 状态 |
|---|---|---|
| 翻新旧课件（保留内容，更新模板/图示/排版） | 课件放入 `inbox/`，指示 AI"翻新 inbox 中的课件" | 可用 |
| 从零制作 PPT（基于论文、代码、项目素材） | 素材放入 `inbox/`，指示 AI 生成 | 建设中（大纲确认页可用） |
| 复用自有模板制作新 PPT | 提供模板文件，指示 AI 导入 | 部分可用（配色与字体自动提取；母版结构复用建设中） |

## 环境要求

- Windows，已安装 PowerPoint（旧格式转换与逐页截图依赖本机 Office）
- Python 3.10+；首次初始化虚拟环境：

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
```

## 使用流程

1. **投放文件**：将待处理的 .ppt/.pptx 及素材放入 `inbox/`。AI 仅读取该目录，
   处理前会先给出清单并征询确认。
2. **发出指令**：对任意 AI 助手（Claude Code、pi 等）说明：

   > 读 `c:/你的路径/20261020_ppt_station/SKILL.md`，翻新 inbox 里的课件。

3. **网页确认与审核**：AI 依次打开两个页面——
   - **选择页**：呈现体检诊断与处方建议（画幅、风格、页面范围、图形页策略）。
     确认后开始生成；也可选择"由 AI 决定，先出 10 页试稿"。
   - **审核工作台**：左侧原页截图、右侧新稿。逐页裁决（保留原图 / 通过 / 重绘），
     或在意见框以自然语言提出修改要求，由 AI 异步处理后提示查看。
     页面元素亦可直接编辑（拖动、改字、缩放、增删，保存时自动通过质量检查）。
4. **导出**：审核完成后指示 AI 导出，成品位于 `projects/<任务名>/exports/`。

## 常用命令

```bash
.venv/Scripts/python station/server.py    # 启动审核网页 → http://127.0.0.1:7610
```

工作台快捷键：`1` 保留原图 · `2` 通过 · `3` 重绘 · `S` 星标 · `←/→` 翻页 · `Ctrl+K` 命令面板。

## 目录说明

```
inbox/                  投料区（用户投放，AI 只读盘点）
projects/<任务名>/
  exports/*.pptx        最终成品
  pages/                每页的截图、新稿与裁决记录（支持中断后续接）
```

## 设计原则

1. **图形不丢失**：旧课件中的图示在新版中必定可见（保底贴原图，可再升级为重绘）
2. **用户决策**：风格选择与逐页裁决均由用户确认，AI 仅提供建议与执行
3. **状态可恢复**：全部状态以文件保存，审核中断后可随时继续
