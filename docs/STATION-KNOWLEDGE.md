## 1. 渐进讲解序列：跨页保位重绘

**发现**（2026-10-28，用户指出 P7-16）：老课件常见"同一张图逐页加一点"的讲法。
实测该课件 P7→P15 相邻页元素保持率 70-96%，而独立页对照组仅 4%——**50% 阈值即可自动判定**。

**规矩**：序列组内页面**禁止逐页独立重绘**。以序列首页为基准建立画布，后续页只做
增量变更（新增/修改/删除的元素），固定元素坐标逐页继承——否则前后页"本来固定在
同一位置的框"漂移，讲解的推进逻辑就断了。

**落点**：`station/prep/sequence.py`（检测入 diagnosis.json）+ SKILL §3 Step4 规则。
本次实测还多发现了两组隐性序列（P27-29、P77-79）——人眼容易漏，机器扫全库。

## 2. "划重点"有三种形态，两种藏在 XML 盲区

**发现**（2026-10-28，用户三次目检逼出来的）：老师强调重点的手段有三种，
对应三种技术形态，漏一种就丢一批语义：

| 形态 | 藏在哪 | 抓法 |
|---|---|---|
| 文字颜色/加粗 | run 属性——但可能用 `schemeClr` 主题引用（本例红字=超链接色恰好映射红） | python-pptx，两种 color type 都要读 |
| 文字级下划线 u= / 手画线形状 | rPr 属性 / 独立 autoshapes（细长形状，如 P42 的 9 条 832px 横线） | 前者读 rPr@u，后者按"细长"启发式入 line_marks 带坐标 |
| **ink 墨迹**（放映时手绘） | `ppt/ink/ink*.xml` 独立部件——**完全不在 slide 形状树里** | XML 解析成本高 → 视觉标注层（vision.md）承载 |

**规矩**：初稿生成必须重现全部强调语义（按新模板的强调语汇翻译，如红字→accent 色）；
独立线形状**保持独立形状导出**，不转成文字下划线属性（形态保真，PowerPoint 里可
单独选中/删改）。

## 3. 中间文档跨模型接力（视觉盲盒工作流）

**发现**（2026-10-28）：图形重绘需要视觉，但强语言模型未必有视觉；反过来视觉模型
未必擅长排版生成。解法是**视觉模型只负责"看"并落 vision.md**（拓扑/颜色语义/排版
层级/备注四节），语言模型照文档重画——**中间文档即跨模型记忆**，切模型不丢信息。

**规矩**：agent 无视觉时必须停下向用户提供三选一（切换视觉模型/派视觉子会话/
跳过=图形页全贴原图），绝不猜画。视觉自检同理：导出后截图由有视觉的会话回看。

## 4. 诊断先行：确认包是"诊断报告+处方"而非问卷

**发现**（2026-10-27）：准备链阶段机器能测的远比想象多——画幅/主题色/实际用色
（老课件"主题蓝正文绿"要报实况）/字体混排/框线图统计/拥挤页。确认包先给诊断再给
带理由的处方（每项预选推荐），用户成本从"填问卷"降到"扫一眼点确认"。
三通道兜底：选择页点选（零打字）/聊天快答（回"1A"）/完全委托（"你定"→先出 10 页试稿）。

## 5. 审核环的"双入口单队列"

**发现**（2026-10-27 设计定稿）：聊天与网页是同一批文件的两个入口——意见框提交
与聊天里说"第 5 页加时间轴"进同一个待办队列；裁决/草稿/意见全落盘，**换会话、
不开网页都能接手**。网页只是快捷方式，聊天永远全功能，文件是唯一真相。

## 6. 保底贴图：图绝不能丢的铁律实现

**发现**（源自 v0 血泪，本次 M2 验证）：识别为图形页但无把握重绘时，**贴原图**
（逐页 PNG 等比入画幅）永远保真；重绘页才追求可编辑矢量。三条路各有出口：
保留原样（贴图）/通过当前稿/重绘——且重绘失败随时可退回贴图。
